# Appearance

**Account › Settings** (SET-01) controls how the app looks.

- **Mode:** **Light**, **Dark**, or **Match system** (the default).
- **Light theme:** Teal Ledger, Indigo Root, **Moss Paper** (default), Coral Clay, or Spore Pink.
- **Dark theme:** Night Soil, Deep Teal, Graphite Spore, **Forest Floor** (default), or Ember Clay.

The app uses the light theme you picked in light mode and the dark one in dark mode. Wallpaper-based colours (Material You) are off, because the Substratal themes are the product palette. If you use the system's high-contrast setting, it takes over.

!!! note
    Your choice is saved on this device for now. It will sync across devices once the API can store it.
