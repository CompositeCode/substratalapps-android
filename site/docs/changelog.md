# What's new

## 0.1.0 (in development)

The first build of the Android management app.

- **Shell:** bottom bar on phones, rail on small tablets, full side menu on tablets and Chromebooks. All 85 screens have their own link and deep link. Screens that aren't built yet show what they'll do.
- **Sign in** with email, password and two-factor code or recovery code.
- **Users:** search, status filters and infinite scroll.
- **Applications:** every application for staff, with a review-queue filter; your own applications for developers.
- **Manage hub** with Operations, Administration and Developer.
- **Operations Overview** (preview, with sample data).
- **Account** and **Settings**, with the ten Substratal themes.
- **Help** on every screen, linked to this site.
- Uses API version **1** through the `Substratal-Version` header, and warns when that version is deprecated.
