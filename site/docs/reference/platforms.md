# Platforms

Every platform's app has the same screens, IDs, links and help pages. They differ only where the platform's own conventions differ.

| Platform | Status | Push notifications | Repository |
|---|---|---|---|
| **Android** | Skeleton: navigation, sign-in, Users, Applications, Settings, Account; Operations Overview in preview | Firebase Cloud Messaging (planned) | `substratalapps-android` |
| **Web** | In development | Web Push | `substratalapps.com-web` |
| **iOS / iPadOS** | Planned | APNs | `substratalapps-ios` |
| **macOS** | Planned | APNs | `substratalapps-macos` |
| **Windows** | Planned | Local notifications, by polling | `substratalapps-windows` |
| **Linux** | Planned | Local notifications, by polling | `substratalapps-linux` |

The [screen reference](screens/index.md) shows the state of each screen in the Android app. Other platforms will publish their status here as they ship.
