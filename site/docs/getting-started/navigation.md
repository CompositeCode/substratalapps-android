# Find your way around

The app arranges the same sections differently depending on screen width.

=== "Phones"

    A bar along the bottom has five destinations:

    | Destination | What's there |
    |---|---|
    | **Home** | The apps you can use |
    | **Inbox** | Notifications from Substratal and your apps |
    | **Orgs** | Organizations you belong to |
    | **Manage** | Everything for running the platform: Operations, Administration and Developer. Only shown if you have rights in one of them |
    | **Account** | Your profile and security, plus Plan & Billing, Settings, and Help & documentation |

=== "Small tablets and foldables"

    The same five destinations, in a rail down the left side.

=== "Tablets and Chromebooks"

    A menu down the left shows every section at once:

    - **Personal:** Home, Inbox, Organizations, Account, Plan & Billing, Settings
    - **Operations:** Overview, Traffic & latency, Errors, Usage, Jobs & delivery, Alerts, Security events, Configuration, Integrations, Cost
    - **Administration:** Users, Access, Roles, Audit Log, Send notification
    - **Developer:** Applications, API Keys, Webhooks, Tenant
    - **Help & documentation**

## Help on every screen

Every screen has a **?** button in its top bar. It opens that screen's page in this documentation, for the version of the app you're running.

## Links that open the app

Links to `https://dashboard.substratalapps.com/…`, for example in an invitation email, open in the app when it's installed. So do `substratal://` links, such as `substratal://admin/users`. Each screen's page in the [screen reference](../reference/screens/index.md) lists its link.

## Screens that aren't built yet

Some screens are marked **Planned**. You can still open them; they show what the screen will do and which API calls it uses. Screens marked **Preview** have their final layout but show sample data.
