# Install the app

=== "Android"

    The Android app runs on Android 8.0 (API 26) and later, on phones, tablets, foldables and Chromebooks.

    - **Staff and testers:** install the build your administrator shares through the Google Play internal testing track.
    - **Everyone else:** the app will be listed on Google Play when it's released.

    The app needs an internet connection. It stores your session in the device's hardware-backed keystore, and nothing is included in device backups.

=== "Web"

    The web app will run at `https://dashboard.substratalapps.com`. It's being built.

=== "iOS, macOS, Windows, Linux"

    Being built. See [Platforms](../reference/platforms.md) for the state of each one.
