# Substratal Help

Substratal's management apps let you run the Substratal Apps platform:

- the people who use it
- what each person can reach
- the applications built on it
- the keys and webhooks those applications use
- the health of the API itself

This site is the reference for every version of the app: Android today, then Web, iOS, macOS, Windows and Linux. All of them share the same screens, the same screen IDs and the same help pages.

## Which version am I reading?

The version menu at the top of every page matches the app's version. **latest** is the most recent release, and **dev** follows what's being built. When you open help from inside the app, it opens the pages for your version.

The **Platform API** has its own version, sent with every request in the `Substratal-Version` header. This version of the app uses API version **1**. See [API versions and changes](developers/api/versions.md).

## Can't find it?

Use search (press ++slash++ or ++s++), check the [FAQ](faq.md), or look a screen up by its ID in the [screen reference](reference/screens/index.md). Every screen in the app has a help button (**?**) that opens its page here.
