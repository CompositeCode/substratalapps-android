## Using this screen

Enter the 6-digit code from your authenticator app. The code is only valid briefly, so if you take too long you'll go back to sign-in.

- **Use a recovery code** switches to a recovery code. Each one works once.
- **Back to sign in** cancels.

If you've lost both your device and your recovery codes, an administrator with `users.manage` can reset two-factor for you after checking who you are.
