## Using this screen

The Overview answers *is the API OK right now?*

- **Components:** the API, MCP server, Stripe webhook, delivery worker, scheduled jobs and database.
- **Last 24 hours:** requests, server error rate, and p95 latency against the 150 ms target.
- **Alerts:** anything firing. Tap one to open Alerts.
- **Budget:** this month's AWS spend against the $75 warning budget.

In this preview only the API's status is live; the rest is sample data, and the banner at the top says so. See [Operations](../../guides/operations.md).
