## Using this screen

On phones and small tablets, **Manage** gathers everything for running the platform into one list:

- **Operations:** monitoring the API
- **Administration:** users, access, roles, audit log, notifications
- **Developer:** applications, API keys, webhooks, tenant

You only see the items your account can use. Items marked **Preview** or **Planned** aren't fully built yet. On tablets and Chromebooks these sections are in the side menu instead.
