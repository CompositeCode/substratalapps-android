## Using this screen

Staff (`applications.manage`) see every application. Developers see the ones they own.

- **Approved** shows live applications.
- **Review queue** shows submissions waiting for a decision, oldest first.
- **Register application** starts a new one. See [Register an application](../../tutorials/register-an-application.md).

Each row shows the app's ID (`app_…`), its tier (Free or Standard) and its review status.
